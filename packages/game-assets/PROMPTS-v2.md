# v2 단순화 프롬프트

- 방식: 내장 `image_gen` 편집 도구, `transparent_background: true`.
- 날짜: 2026-10-20 (Asia/Seoul).
- 입력 1: 사용자가 업로드한 작은 캐릭터 예시(표현 밀도·스타일 참고).
- 입력 2: 같은 ID의 기존 v1 PNG(의상·색상·동작 유지 대상).
- 민트 이외의 입력 3: 이번에 단순화한 민트 PNG(시리즈 공통 표현 기준).
- PNG 원본은 도구 출력 그대로 저장했으며, atlas는 실제 해상도와 알파 경계를 읽어 별도 생성한다.
- 프롬프트의 픽셀 수·색 수는 그림 방향을 지정한 값이며, 정확한 픽셀 격자·팔레트 수를 검증한 결과는 아니다.
