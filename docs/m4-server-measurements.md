# M4 서버 6인 로컬 실측

2026-10-22 16:07 KST에 Windows x64 / Node 22.20.0에서 한 번 측정했다.
서버는 별도 Node 자식 프로세스, Socket.IO 클라이언트 6개는 별도 측정 프로세스다.
DB는 `127.0.0.1:54329`의 격리된 `deskbrawl_test`만 사용했다.
서버는 OS가 할당한 임시 포트에 바인딩하며 기존 개발 서버·DB를 변경하지 않는다.
테스트가 생성한 기기·방·초대만 종료 시 삭제한다.

## 방법과 범위

- 호스트 1명 + 방문자 5명이 하나의 1280×720 월드를 공유한다.
- 서버 fixed tick은 50ms이다. 각 클라이언트는 약 100ms 간격으로 이동 입력을 보낸다.
- 정상 구간 약 5초, 입력을 120ms 늦추고 전체 입력 중 매 네 번째 의도를 전송하지 않는 구간 약 5초를 순서대로 측정했다.
- 입력 ack는 서버 검증·명령 큐 수락을 의미한다. 실제 화면 반응 시간이나 tick 적용 완료가 아니다.
- 입력 전송 직후부터 ack까지의 시간과, 인위적 대기를 포함한 입력 의도 생성부터 ack까지의 시간을 따로 기록한다.
- 스냅샷 크기는 호스트가 받은 JSON을 UTF-8로 직렬화한 바이트 수다. Socket.IO·WebSocket·TCP 오버헤드는 포함하지 않는다.
- CPU는 클라이언트와 분리된 서버 프로세스의 `process.cpuUsage()` 차이를 실제 경과 시간으로 나눈 단일 코어 기준 비율이다.
- RSS는 서버 프로세스 값만 기록했다. peak는 시작 이후 100ms 간격으로 관측한 최대 RSS로, 정확한 OS high-water mark가 아니다.
- 게스트·호스트를 각각 한 번 끊고 120ms 대기 후 재인증·복구했다. 동일 월드·6명 유지, visitId·토큰 교체, 이전 visitId 입력 거부도 함께 확인했다.

## 재현

프로젝트가 요구하는 Node 22와 pnpm을 사용하고 격리 DB에 마이그레이션을 먼저 적용한다.
`TEST_DATABASE_URL`에는 본인 환경의 테스트 DB 자격 증명을 넣고 커밋·로그에 남기지 않는다.
측정 스크립트는 로컬 주소와 이름에 `test`가 포함된 DB만 허용한다.

```powershell
$env:TEST_DATABASE_URL = '<로컬 격리 PostgreSQL 테스트 DB URL>'
$env:DATABASE_URL = $env:TEST_DATABASE_URL
pnpm --filter @deskbrawl/server db:migrate
pnpm --filter @deskbrawl/server build
$env:M4_BENCH_PHASE_MS = '5000'
$env:M4_BENCH_OUTPUT = "$PWD/.local/m4-server-benchmark.json"
node apps/server/test/m4-benchmark.cjs
```

측정 구현: [m4-benchmark.cjs](../apps/server/test/m4-benchmark.cjs).
기본 구간 길이는 5,000ms이며 `M4_BENCH_PHASE_MS`로 1,000~30,000ms 범위에서 바꿀 수 있다.
JSON 출력에는 자격 증명·채팅 내용·기기 식별자를 넣지 않는다.

## 미검증 항목과 복구 한계

이번 유실은 **애플리케이션의 입력 의도를 보내지 않는 방식**이다. 실제 네트워크 패킷 유실,
TCP 재전송, Wi-Fi 지연·단절, 6대 PC, PixiJS 렌더링, Tauri·Win32 포커스, 설치·서명·배포를
검증한 결과가 아니다. 채팅·공격을 계속 사용하는 부하, 장시간 메모리 안정성도 별도 검증이 필요하다.

자동 복구 유예는 현재 임시 정책인 10초다. 서버 재시작·유예 만료·강퇴·집중 모드 퇴장·명시적
이탈은 새 세션이 필요하다. 복구 시 서버가 토큰을 교체한 직후 연결이 끊겨 클라이언트가
`visit:joined`와 ack를 모두 놓치면, 예전 토큰은 재사용할 수 없다. 이때 복구를 성공으로
가정하거나 오래된 명령을 재전송하지 않고 실패를 표시하며, 마지막 단절 후 유예가 끝나면
보류 멤버십이 정리된다. 토큰 교체 자체의 확인 프로토콜은 이번 M4의 범위에 추가하지 않았다.
