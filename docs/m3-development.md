# M3 작업 모드·호스트 제어

M3는 기존 2인 방문 흐름에 집중 모드, 방문자 제어와 트레이 상주를 추가한다. 서버와 데스크톱을 함께 갱신한 뒤 서버를 재시작한다. 로컬 서버·PostgreSQL 준비는 [M2 개발 안내](m2-development.md)를 따른다.

## 사용 동작

- **Ctrl+Shift+G** 또는 저장한 전환 단축키로 현재 작업 창을 유지하면서 WORK/PLAY를 전환한다. 홈 창이 최소화돼 있어도 전환하며 게임 키는 Windows 네이티브 훅으로 받는다. Esc·홈 창 닫기·오버레이 숨김·세션 전환 시 입력을 중단한다. FOCUS에서는 네이티브 PLAY를 거부하고, 연결 종료 후에는 로컬 캐릭터와 로컬 PLAY를 복구한다.
- **집중 모드 켜기**는 PLAY를 끝내고 오버레이를 숨긴다. 호스트의 기존 방문자는 `ROOM_UNAVAILABLE` 사유로 종료되며 새 입장도 거부한다. 방문 중에 켜면 방문을 끝내고 자신의 공간을 집중 모드로 연결한다.
- 집중 모드를 끄면 오버레이를 복구하고 기존 방문 링크를 다시 사용할 수 있다. 집중 모드는 실행 중 상태이며 앱을 다시 시작하면 WORK로 시작한다. DB 스키마 변경은 없다.
- 호스트는 접속자 목록에서 **내보내기** 또는 **모두 내보내기**를 실행한다. 방문자는 `KICKED` 안내를 받고 입력·렌더링 세션을 정리한다. 이전 `visitId`의 이동·공격은 서버가 거부한다.
- 강퇴는 영구 차단이 아니다. 유효한 링크를 가진 방문자는 다시 들어올 수 있다. 재입장을 막으려면 링크를 폐기·재발급하거나 집중 모드를 켠다. 링크 재발급만으로 현재 방문자를 종료하지는 않는다.
- 홈 창의 **X**, 화면 상단 **종료**, 트레이 **종료**는 앱·소켓·오버레이·트레이를 함께 종료하고 PLAY 입력·네이티브 키보드 훅을 해제한다. 홈 창을 최소화하면 호스트 세션과 오버레이를 유지하며 트레이 **홈 열기**로 복원한다.
- 트레이에서 **집중 모드**, **링크 복사**를 사용할 수 있다. 링크 복사는 현재 실행에서 발급한 링크가 있을 때만 활성화하며 폐기·연결 종료 시 비활성화한다. Windows 클립보드에는 해당 링크만 쓴다.

## 계약과 경합 처리

공유 프로토콜 v1에 선택 필드 `room:host.focused`와 아래 이벤트를 추가했다. 기존 스냅샷 형식과 REST·IPC의 기존 필드는 유지한다. 새 클라이언트는 집중 상태를 전송하므로 기존 서버와 혼용하지 않고 서버를 먼저 갱신한다.

| 이벤트 | 요청 | 권한·결과 |
| --- | --- | --- |
| `room:focus` | `visitId`, UUID `commandId`, `focused` | 현재 공간의 호스트만 변경 |
| `visit:kick` | `visitId`, UUID `commandId`, `targetPlayerId` | 호스트만 방문자를 종료 |
| `visit:clear` | `visitId`, UUID `commandId` | 호스트를 제외한 방문자 종료 |

서버의 기존 직렬 큐를 초대 발급·폐기, 입장, 호스트 제어가 공유한다. 입장 후 Socket.IO 방에 연결되는 동안 퇴장한 경우에도 멤버십을 다시 검사해 방 구독을 제거한다. 최근 128개 호스트 명령 ID는 중복 실행을 막으며 같은 ID에 다른 내용을 보내면 거부한다. 클라이언트는 제어 명령을 자동 재시도하지 않는다.

집중 시 서버 입력·예약 공격·투사체·효과를 초기화하고 시뮬레이션을 멈춘다. 클라이언트는 입력을 즉시 멈추며 전환 전에 보낸 입력의 늦은 실패 응답이 호스트 연결을 종료하지 않도록 구분한다. 같은 tick의 멤버 변경 스냅샷도 수락해 강퇴된 캐릭터를 즉시 제거한다.

새 IPC `focus_read`, `focus_set`, `invite_publish`는 main capability와 Rust 창 라벨 검사 양쪽에서 제한한다. 오버레이는 집중·초대 상태를 변경하거나 장치 인증 정보를 읽을 수 없다.

## 검증

실행 결과와 재현 명령은 [M3 검증 기록](m3-validation.md)에 정리한다. 단축키·방문 오버레이·호스트 종료 복귀 변경은 [LAN 피드백 수정 검증](desktop-lan-fixes-validation.md)을 참고한다. M4에서 정원은 호스트 포함 6명으로 확장했고 재연결 복구와 실시간 채팅을 추가했다. 최신 사용법은 [M4 안내](m4-development.md)를 따른다.
