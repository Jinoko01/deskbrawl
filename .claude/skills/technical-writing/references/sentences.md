# 문장 다듬기

수동태를 피하거나 해요체를 쓴다고 해서 쉬운 글이 되는 것은 아니다. 정보를 잘 구조화했더라도 세부 내용이 어려운 문장으로 표현되면 전달력이 떨어진다.

---

## 1. 문장의 주체를 분명하게 하기

기술 문서의 독자는 개발자이고, 문서에 적힌 작업을 실제로 수행하는 것도 개발자다. 즉 **읽는 사람이 곧 행동의 주체**다. 명시적으로 드러내지 않더라도 개발자가 주체라는 전제로 쓰면 문장이 자연스러워진다.

### 도구나 기술을 행동의 주체로 쓰지 않는다

|       | 문장                                                                        |
| ----- | --------------------------------------------------------------------------- |
| Don't | 이 라이브러리는 데이터베이스 초기화를 수행해요                              |
| Do    | 이 명령어를 실행하면 데이터베이스를 초기화할 수 있어요                      |
| Don't | 이 코드는 API 요청으로 인증 토큰을 추가해요                                 |
| Do    | 이 코드를 사용하면, API를 요청했을 때 자동으로 인증 토큰을 추가할 수 있어요 |

**예외**: 도구나 기술 자체의 동작을 설명할 때는 주체가 기술이어도 된다.

> Impression 로그는 두 가지 방식으로 동작해요.
>
> 1. 특정 접근성 요소가 화면에 나타나면 자동으로 수집돼요.
> 2. 특정 DOM 요소를 직접 지정해서 뷰포트에 나타날 때 로그를 수집할 수 있어요.

### 능동형으로 표현한다

수동형은 문장을 복잡하게 만들고 주체를 흐린다.

|       | 문장                                                  |
| ----- | ----------------------------------------------------- |
| Don't | 애플리케이션이 실행되기 전에 설정이 완료되어야 합니다 |
| Do    | 애플리케이션을 실행하기 전에 설정을 완료하세요        |
| Don't | 변경 사항이 적용된 후 다시 빌드되어야 합니다          |
| Do    | 변경 사항을 적용한 후 다시 빌드하세요                 |

## 2. 필요한 정보만 남기기

### 한 문장에 하나의 생각만 담는다

|       | 문장                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------ |
| Don't | 버튼을 클릭하면 다음 단계로 이동하게 되며, 그 이후의 작업을 진행할 수 있습니다                               |
| Do    | 버튼을 클릭하면 다음 단계로 이동합니다. 이동 후 이어서 작업을 진행하세요                                     |
| Don't | 이 API를 호출할 때 요청 헤더를 포함해야 하며, 올바른 인증 정보를 제공해야 정상적으로 응답을 받을 수 있습니다 |
| Do    | 이 API를 호출할 때 요청 헤더와 인증 정보를 포함하세요                                                        |

### 메타 담화를 최소화한다

메타 담화는 '말에 대한 말'이다. 핵심 메시지가 아니라 메시지를 보조하는 표현으로, 많아지면 문장의 밀도가 떨어진다.

- 흐름을 설명하는 표현: "다음으로", "앞서 설명했듯이", "이제 알아보겠습니다"
- 불필요한 강조: "사실은", "솔직히 말하면", "결론적으로"
- 반응을 유도하는 표현: "아시겠지만", "여러분도 아실 것입니다"

|       | 문장                                                                              |
| ----- | --------------------------------------------------------------------------------- |
| Don't | 앞에서 설명했지만, 결론은 이 설정을 변경하는 것이 가장 효과적인 방법이라는 겁니다 |
| Do    | 이 설정을 변경하는 것이 가장 효과적인 방법입니다                                  |
| Don't | 아시다시피, 이 설정은 성능에 영향을 줍니다                                        |
| Do    | 이 설정은 성능에 영향을 줍니다                                                    |

## 3. 구체적으로 쓰기

### 명사 대신 동사를 쓴다

동사에서 파생된 명사("설정 수행", "검토 진행")는 의미를 흐린다.

|       | 문장                                                                  |
| ----- | --------------------------------------------------------------------- |
| Don't | 코드 최적화 진행 후 배포 수행이 필요합니다                            |
| Do    | 코드를 최적화한 후 배포하세요                                         |
| Don't | MongoDB 연결 정보 설정 및 초기화가 필요합니다                         |
| Do    | MongoDB에 연결할 호스트와 포트를 설정하고 데이터베이스를 초기화합니다 |

### 모호한 표현을 쓰지 않는다

"가능성이 있다", "일부 경우", "필요할 수도 있다"는 문서의 신뢰도를 떨어뜨린다.

|       | 문장                                                         |
| ----- | ------------------------------------------------------------ |
| Don't | 설정 파일을 변경하면 기존 설정이 영향을 받을 수도 있습니다   |
| Do    | 설정 파일을 변경하면 기존 설정이 삭제됩니다                  |
| Don't | 일부 브라우저에서 정상적으로 동작하지 않을 가능성이 있습니다 |
| Do    | Internet Explorer에서는 정상적으로 동작하지 않습니다         |

### 누가, 무엇을, 어디에, 어떻게 하는지 쓴다

독자가 맥락에 의존하지 않고 문장 하나만으로 이해할 수 있어야 한다.

|       | 문장                                                                                        |
| ----- | ------------------------------------------------------------------------------------------- |
| Don't | 파일을 업로드하면 자동으로 저장됩니다                                                       |
| Do    | 사용자가 파일을 업로드하면 서버에 자동으로 저장됩니다                                       |
| Don't | 설정을 변경하면 적용됩니다                                                                  |
| Do    | 관리자가 설정을 변경하면 변경 사항이 프로덕션 환경에 즉시 적용됩니다                        |
| Don't | 에러가 발생하면 로그를 확인하세요                                                           |
| Do    | 에러가 발생하면 애플리케이션 서버에서 에러 로그 파일(`/var/log/app/error.log`)을 확인하세요 |

### 실제 동작을 이해할 수 있게 쓴다

업계에서만 통하는 표현은 실제 동작을 흐린다.

|       | 문장                                                                                                                    |
| ----- | ----------------------------------------------------------------------------------------------------------------------- |
| Don't | 에러가 발생하면 Exception을 던집니다 — 호출한 쪽에 전달한다는 뜻인지, 단순히 오류를 반환한다는 뜻인지 상황마다 달라진다 |
| Do    | 에러가 발생하면 예외(Exception)를 일으킵니다                                                                            |
| Don't | 클라이언트가 서버를 찔러서 응답을 확인합니다                                                                            |
| Do    | 클라이언트가 서버에 요청을 보내서 응답을 확인합니다                                                                     |

### 구체적인 수치나 기준을 제시한다

"값", "설정", "성능" 같은 단어와 "많을 때", "빠르게" 같은 표현은 맥락에 따라 다르게 해석된다.

|       | 문장                                                                |
| ----- | ------------------------------------------------------------------- |
| Don't | 데이터가 많을 때는 성능이 저하될 수 있습니다                        |
| Do    | 데이터가 10,000건을 넘으면 응답 시간이 1초 이상 걸립니다            |
| Don't | 파일 크기가 클 때는 업로드에 시간이 걸립니다                        |
| Do    | 파일 크기가 100MB를 넘기면 업로드에 최소 30초 이상 걸릴 수 있습니다 |

### 참조되는 내용의 맥락을 설명한다

다른 단락에서 언급한 변수나 설정값을 다시 쓸 때는 어디에서 설명했는지 알려준다. 반대로 처음 언급할 때는 나중에 어디에서 쓸지 알려준다.

**Don't**

```
API 키를 생성합니다. apiKey 변수에 저장합니다.
...
apiKey로 API 인증을 수행합니다.
```

1단계에서는 `apiKey`를 어디에 쓸지 알 수 없고, 3단계에서는 값을 어디서 얻었는지 확인하려고 앞부분을 다시 읽어야 한다.

**Do**

```
API 키를 생성하고 apiKey 변수에 저장합니다. 이 키는 3단계에서 API 인증에 사용됩니다.
...
1단계에서 apiKey에 저장한 API 키로 인증합니다.
```

## 4. 자연스러운 한국어 표현 쓰기

### 불필요한 한자어를 제거한다

"수행하다", "실행하다", "진행하다"는 대개 빼도 의미가 전달된다.

|       | 문장                                    |
| ----- | --------------------------------------- |
| Don't | 로그 파일을 삭제하는 작업을 수행합니다  |
| Do    | 로그 파일을 삭제합니다                  |
| Don't | 설정 변경을 수행한 후 적용을 진행합니다 |
| Do    | 설정을 바꾼 뒤 적용합니다               |

### 번역체 명사형을 동사로 푼다

영어는 동사를 명사형(`-tion`, `-ing`, `-ment`, `-ance`)으로 바꿔 쓰는 것이 자연스럽지만 한국어는 동사 그대로 쓰는 편이 자연스럽다.

|       | 문장                                                                                   |
| ----- | -------------------------------------------------------------------------------------- |
| Don't | API 키를 이용한 사용자 인증 처리가 완료된 후, 데이터베이스 접속 설정 진행이 가능합니다 |
| Do    | API 키로 사용자를 인증한 후, 데이터베이스에 접속하도록 설정할 수 있습니다              |
| Don't | 시스템 모니터링 수행을 통해 서버 성능 측정 작업을 실시하게 됩니다                      |
| Do    | 시스템을 모니터링해서 서버 성능을 측정합니다                                           |
| Don't | 이 API를 통해 데이터를 가져올 수 있습니다                                              |
| Do    | 이 API로 데이터를 가져올 수 있습니다                                                   |

## 5. 일관되게 쓰기

### 공식 기술 용어를 따른다

개발 도구와 언어 이름은 공식 문서나 위키피디아 표기를 따른다. 대소문자에 주의한다.

|       | 문장                                                             |
| ----- | ---------------------------------------------------------------- |
| Don't | K8을 사용하면 애플리케이션 배포가 쉬워집니다                     |
| Do    | 쿠버네티스(Kubernetes)를 사용하면 애플리케이션 배포가 쉬워집니다 |
| Don't | 이 문서에서는 "자바스크립트 비동기 실행 방식"을 설명합니다       |
| Do    | 이 문서에서는 "JavaScript의 비동기 실행 방식"을 설명합니다       |

### 같은 개념을 여러 방식으로 표현하지 않는다

|       | 문장                                                                                                                                                             |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Don't | 파일을 **추가**하려면 '파일 선택' 버튼을 클릭하세요. 파일을 **첨부**한 후 '저장'을 누르면 업로드가 완료됩니다. 필요하면 파일을 다시 **넣을** 수 있습니다         |
| Do    | 파일을 **업로드**하려면 '파일 선택' 버튼을 클릭하세요. 파일을 **업로드**한 후 '저장'을 누르면 업로드가 완료됩니다. 필요하면 파일을 다시 **업로드**할 수 있습니다 |

### 약어는 처음 등장할 때 풀어쓴다

괄호 안에 전체 이름을 쓰고, 약어와 괄호 사이는 띄우지 않는다.

|       | 문장                                                                                                |
| ----- | --------------------------------------------------------------------------------------------------- |
| Don't | 이 기능은 SSR을 지원합니다                                                                          |
| Do    | 이 기능은 SSR(Server-Side Rendering)을 지원합니다                                                   |
| Don't | CSR은 초기 페이지 로딩 속도를 높이는 데 유용합니다                                                  |
| Do    | 클라이언트 사이드 렌더링(Client-Side Rendering, CSR)은 초기 페이지 로딩 속도를 높이는 데 유용합니다 |

### 외래어 표기는 사용 빈도를 고려한다

맞춤법을 그대로 따르기보다 업계에서 일반적으로 쓰이는 표기를 고려한다. 토스는 구글 트렌드 기준으로 외래어 표기법보다 5배 이상 많이 쓰이는 표기가 있으면 그 표기를 쓴다.

|       | 표기       |
| ----- | ---------- |
| Don't | 프런트엔드 |
| Do    | 프론트엔드 |

## 연습 문제

직접 고쳐 본 뒤 답과 비교한다.

1. 능동형으로 바꾸기 — `이 문서는 업데이트된 이후 다시 검토될 필요가 있습니다.`
2. 긴 문장 나누기 — `사용자는 설정 파일을 변경한 후 저장하고, 변경 사항이 적용되었는지 확인한 다음, 필요하면 서버를 다시 시작해야 합니다.`
3. 명사를 동사로 — `데이터 백업 진행 후 시스템 설정 변경이 필요합니다.`
4. 모호함 제거 — `일부 환경에서는 소프트웨어 설치 후 정상적으로 실행되지 않을 가능성이 있습니다.`
5. 생략된 정보 채우기 — `데이터베이스에 연결하면 자동으로 동기화됩니다.`
6. 수치 제시 — `요청량이 많으면 응답 시간이 느려질 수 있습니다.`
